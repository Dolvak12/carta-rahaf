# بطاقة حب — لرهف 💖🌹

مشروع رسالة رقمية تفاعلية مخصصة لـ **رهف**.

## ✨ المميزات

### 1. تخصيص كامل
- **رسالة عاطفية**: رسالة حب مكتوبة بالعربية خصيصًا لرهف.
- **صورة شخصية**: إمكانية إضافة صورة (`image_01.jpg`) مع تحميل ذكي.

### 2. تصميم بصري فاخر ("Glassmorphism")
- **إطار الصورة**: تصميم بإطار متدرج وحلقة دوارة مضيئة.
- **أزرار**: تأثير لمعان عند التفاعل مع ظلال عميقة.
- **جسيمات مختلطة**: مطر من:
  - 🌹 بتلات ورد واقعية.
  - ❤️ قلوب عائمة.
  - ✨ بريق ذهبي.

### 3. محسّن للجوال (Mobile-First)
- **كثافة المطر**: مضبوطة لتبدو جميلة على الشاشات الصغيرة.
- **تأثير "التنفس"**: حركة نبض لطيفة للبطاقة على الجوال.
- **تصميم متجاوب**: تعديلات في المسافات والأحجام.

### 4. مشغل موسيقى قوي
- **YouTube آمن**: تشغيل عبر iframe.
- **نظام احتياطي**: إذا تعذر التشغيل (متصفح داخلي)، يظهر رابط مباشر.

## 🚀 التشغيل

1. افتح `index.html` في المتصفح.
2. استمتع بمشاهدة الأنميشن الافتتاحي.
3. اضغط "افتح رسالتي" لقراءة الرسالة والاستماع للموسيقى.
